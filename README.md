# Quarter Athletic + Twenty Five Select — 5-Month Brand Strategy

Single-page strategy doc covering both brands' 5-month ad campaign plans, switchable via the top tab bar (Quarter Athletic / Twenty Five Select / Market Watch).

- `index.html` — the live site (also the GitHub Pages entry point)
- **Market Watch** tab holds weekly competitor-research findings, added automatically by a scheduled cloud agent. New weeks are inserted as `<details class="month market-week">` cards between the `WEEKLY-ENTRIES-START`/`WEEKLY-ENTRIES-END` markers in `index.html`, newest first.
